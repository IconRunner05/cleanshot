# Cleanshot

A fast, simple, secure screenshot and markup tool for Windows 11. It is one portable
`cleanshot.exe`: no installer, no admin rights, and no network access.

## Download

Get `cleanshot-X.Y.Z-x64.exe` from [GitHub Releases](https://github.com/IconRunner05/cleanshot/releases).
Each release lists `SHA256SUMS`, a CycloneDX SBOM and a build-provenance attestation beside the
exe; [SECURITY.md](SECURITY.md) says how to check a download and how to report a vulnerability.

## Code signing policy

[SignPath Foundation](https://signpath.org). Signing via SignPath Foundation is pending: releases
are unsigned pre-releases until the first signed release.

## Privacy policy

This program will not transfer any information to other networked systems unless specifically
requested by the user or the person installing or operating it.
